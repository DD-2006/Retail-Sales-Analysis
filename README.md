# Retail-Sales-Analysis
Retail Sales Analytics project using Excel, SQL, Python, and Power BI. Includes data cleaning, SQL database analysis, EDA, RFM customer segmentation, outlier detection, interactive dashboards, KPI analysis, and business insights for sales, customers, stores, staff, and inventory.
